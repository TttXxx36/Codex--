## 🌟 版本综述

Codex++ v1.2.59 是经历第二轮深度稳健重构与性能自愈之后的全新正式版本。本版本在第一轮清理广告与死锁的基础上，全面完成了**核心后端事务闭环**、**敏感凭据零泄露防护**、**万级会话极速 Keyset 分页**、**国产模型与 WeChat 权限协议无缝兼容**，并实施了 **App 14 路由视图完全懒加载解耦** 与 **注入脚本模块化构建**。

## 🚀 核心更新与完善内容 (任务 16 ~ 26 及性能加固)

### 1. 供应商切换真实后端事务与不可变回滚 (任务 16 / BUG-008)
- 消除前端 `Math.random()` 临时内存快照与“撤销假成功”风险；
- 后端在切换前对 `settings.json`、`config.toml` 与 `auth.json` 进行原始字节捕获并计算 SHA-256 唯一指纹，提供后端生成的 UUID 撤销凭证；
- 引入 CAS 防踩踏机制，当文件在外部被手动修改时拒绝静默覆盖，保障用户配置安全。

### 2. 环境变量值级安全校验与 401 隔离 (任务 17 / BUG-009)
- 彻底废除简单按 `OPENAI_` 前缀一刀切清空环境变量的危险行为；
- 引入值级比对与真实哈希校验，仅精准提示真正冲突的变量；清理前自动对明文字符串进行原子备份，并提供图形化的一键还原入口。

### 3. Launcher / Helper 生命周期状态机与安全停机 (任务 18 / BUG-010)
- 为回环 `/helper/shutdown` 停机接口增加随机一次性 Bearer Token 强认证与 POST 方法限制，拦截 OPTIONS 预检请求以防误触停机；
- 动态端口实例隔离，消除端口重定向重试中硬编码 57321 的缺陷；
- 统一收敛运行态状态机（`Absent`, `Starting`, `Ready`, `CdpOnly`），优雅停机赋予 2 秒释放预算。

### 4. 全局多 Token 深度脱敏与错误面板防泄露 (任务 19 / BUG-012)
- 脱敏正则全面支持大小写不敏感 `(?i)bearer\s+`，实现单行多 Bearer Token 全量递归遮罩；
- 覆盖 `sk-` 密钥及常见 URL 查询凭证；
- 诊断面板与导出报告严格采用结构化分类，彻底阻断原始底层报错直接拼接输出带来的凭据外泄风险。

### 5. 纯本地安全会话分享彻底收敛 (任务 20 / BUG-013)
- 从渲染注入端脚本中彻底清除所有残留的 `/share/create` 远程请求、AES 远程加密载荷与 `share.codexpp.cc` 失效公网域名构造；
- 会话分享纯粹保留为纯本地结构化 Markdown 导出与系统剪贴板安全写入。

### 6. 跨平台 CI 自动化门禁守护 (任务 21 / TEST-001)
- 建立 `.github/workflows/ci.yml` 自动化质量流水线，涵盖 Ubuntu 前端依赖锁定检查与 Windows Rust 核心全量工作区编译/测试；
- 本地新增自动化脱敏静态扫描测试，阻断未脱敏凭据混入构建产物。

### 7. App.tsx 架构解耦与 14 路由视图完全懒加载 (任务 22 / PERF-005)
- 将 1.13 万行超大单体 `App.tsx` 中的 14 个路由屏幕（Overview, Sessions, Diagnostics, Relay 等）全部解耦抽离至独立 `views/` 模块；
- 模块顶层采用 `React.lazy` 动态导入并由 `Suspense` 隔离承接，大幅减少主包体积与首屏渲染压力。

### 8. 注入脚本 17 模块工程化拆解与防漂移校验 (任务 23 / PERF-006)
- 将 1.05 万行单 IIFE `renderer-inject.js` 按职责解耦为 `assets/inject/src/` 下的 17 个清晰源码模块；
- 引入 `npm run inject:check` 强校验机制，实现 483,004 字节与 SHA-256 强一致防漂移门禁。

### 9. 真实流式 TTFT 首字节测速与 3xx 判定严谨化 (任务 24 / PERF-007)
- 彻底剔除 `ttftMs = latency * 0.7` 的估算伪造逻辑；
- 在后端改用流式请求，在捕获到首个非空 SSE 分块时真实计时记录 TTFT，非流式显式标为未测；
- 明确将 3xx 重定向归入非成功并给出目标 URL 修复指引。

### 10. SQLite 多 Schema 自适应索引与 Keyset 游标后端闭环 (任务 25 / PERF-008 及加固)
- 支持 `updated_at_ms`、`updated_at`、`created_at_ms` 多 Schema 自适应探测并建立覆盖索引，彻底消除临时 B-Tree 排序；
- 实现全链路双向 Keyset 游标，彻底解决传统 offset 分页带来的深度遍历漂移与漏查问题；
- **运行时加固**：只读库或锁竞争下索引自愈容错，查询不崩溃；单库场景采用 `count_local_sessions` 毫秒级统计，彻底杜绝翻页拉取数万会话 ID 的内存暴增与 GC 停顿。

### 11. 国产大模型协议兼容与安全加固 (任务 26 / BUG-011 及加固)
- 修正微信 app-server 调用的 sandbox 枚举映射（`readOnly`、`workspaceWrite`、`dangerFullAccess`）；
- 针对国产模型上游增加 Responses `custom` 工具自动向 `function` 降级并在响应端无感恢复；
- 脚本市场与更新器增加 HTTPS 强制、5 MiB 大小限制与 SHA-256 完整性写前校验；
- **运行时加固**：针对未声明 `custom` 工具的日常对话，流式输出进行 TCP 零拷贝字节透传，非流式直接原样透传，彻底消除逐 chunk 解析 JSON AST 的延迟损耗。
