## 🌟 版本综述

Codex++ v1.2.58 是经历全面工业级深度重构后的稳定里程碑大版本。本版本彻底消除了困扰原版的广告侵扰、网络外联泄露风险与守护进程端口假死死锁问题，大幅降低了渲染注入端的 CPU/内存占用，并建立起高可靠的数据事务一致性与极速的 SQLite 查询计划索引。

---

## 🚀 核心优化与重大功能落地 (任务 01 ~ 15)

### 1. 纯净体验与隐私安全坚固屏障 (任务 01, 01-B, 01-D)
- **广告与赞助商彻底移除**：全面精简注入端、管理端与 Rust 核心层硬编码的赞助商素材、广告横幅及外链。
- **敏感凭据深度脱敏**：实现日志落盘前的递归遮罩机制，自动屏蔽 `api_key`、`Bearer [REDACTED]` 及鉴权 Token。
- **网络外联阻断**：会话分享全面收敛为纯本地安全 Markdown 导出，彻底阻断向失效公网中转服务器发送私密会话。

### 2. 核心可用性与死锁根除 (任务 02, 03, 04)
- **250ms 死循环重试终止 (PERF-001)**：彻底修复 pureApi 模式下无视重试上限导致的空闲高 CPU 占用，引入指数退避与终末禁用停机状态；针对流式打字引入助手内容直通判定与扫描节流。
- **57321 端口生命周期与平滑停机 (BUG-001)**：底层套接字接入 `SO_REUSEADDR` 消除 `TIME_WAIT` 冲突；新增回环安全 `/helper/shutdown` 优雅停机信令通道，旧进程收到信号主动让位，彻底杜绝重启假死。
- **环境变量安全值级备份与一键还原 (BUG-002)**：彻底修复环境变量清理导致凭据永久销毁的缺陷，提供真实明文字符串原子快照与系统注册表双向无损回滚能力。

### 3. 协议韧性与注入弹性 (任务 06, 07, 08, 09)
- **Responses↔Chat 双向转换与 SSE 状态机契约 (BUG-003)**：为国产智谱 GLM 体系提供图片 Data URL base64 前缀自动剥离；修复 DeepSeek 终末空分块丢失 `call_id` 导致的死循环，固化 `item_id` 严格映射。
- **官方改版弹性选择器降级链 (BUG-004)**：建立 `官方数据属性 → ARIA语义 → 链接结构` 现代弹性选择器链，免疫官方客户端小版本 DOM 与 Tailwind 类名突变。
- **会话事务一致性与 SHA-256 校验防篡改 (BUG-005)**：数据删除支持数据库自动回滚补偿与索引快照保护；为纯 API 模式赋予完整 Undo 令牌；引入 SHA-256 完整性校验与防踩踏冲突预检。
- **自动化 Smoke 回归套件 (BUG-007)**：建立覆盖目标窗口过滤、回环安全、三代选择器、进程状态机流转与凭证防泄漏的自动化 Smoke 测试集。

### 4. 架构解耦与深度性能突破 (任务 10, 11, 12, 13, 14, 15)
- **1.13 万行超大单体 App.tsx 架构拆解 (PERF-002)**：全量接入 `React.memo` 与 `Suspense` 异步路由边界，消除全树无效 Re-render。
- **本地 API 请求/错误脱敏诊断看板 (UX-003)**：捕获最近 20 次请求/Bridge 异常，自动分类 400/401/403/429/超时，提供 100% 本地脱敏排障报告与一键修复引导。
- **多供应商受控并发测速矩阵 (PERF-004)**：以受控并发上限并发探测网络延迟与 TTFT 首字响应时间，提供可解释的客观决策评分与用户显式 opt-in 一键切换。
- **SQLite 覆盖索引消除临时排序与 Keyset 分页 (PERF-003)**：通过 `EXPLAIN QUERY PLAN` 建立复合覆盖索引，彻底消除海量会话检索时的 `USE TEMP B-TREE FOR ORDER BY` 临时排序；经 10,000 条合成会话压测，单次分页查询稳定在 1ms 内。
- **供应商切换差异预检与一键撤销 (UX-002)**：切换前弹出 7 项核心配置差异预检对话框，并自动持久化不可变回滚快照，支持主界面顶部一键秒级撤销。
- **统一视觉规范与响应式排版保护 (UX-001)**：收敛 Button、Badge、Input、Card 核心组件规范，补齐 destructive、success、warning 变体；优化浅色主题文本对比度；增加窄视口文字弹性折行与防截断机制。
