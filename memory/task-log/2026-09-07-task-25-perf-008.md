## 证据与调研记录

- 本地基线：`ensure_session_indexes` 对 archived 索引固定引用 `updated_at_ms` 并吞掉建索引错误；命令层按 `offset + limit + 1` 拉取每个数据库的完整会话行后归并切片；前端仅发送 offset。
- 官方 SQLite 依据：表达式索引要求 WHERE/ORDER BY 中的表达式与建索引表达式保持一致；合适索引可同时避免 ORDER BY 临时 B-Tree。采用同一动态时间表达式生成索引与 keyset SQL，并以 `EXPLAIN QUERY PLAN` 检查稳定语义。
- 复用结论：复用既有 `LocalSession`、`list_local_sessions_limited`、`SessionCursor`、`encodeSessionCursor`/`decodeSessionCursor`、现有 Tauri `CommandResult` 与测试 fixture；不引入分页框架。
- 冲突裁决：任务 brief 要求保持 offset 兼容，优先于“全路径都必须改成游标”的激进方案；因此无 cursor 继续旧 offset 路径，有 cursor 才进入 per-database keyset 分支。

## 诊断闭环

- 最小回归：旧 threads schema 缺少 `updated_at_ms` 时调用 `ensure_session_indexes` 必须成功并建立退化索引；keyset 连续两页必须无重复、无遗漏；前端/SQLite EQP 测试必须识别临时 B-Tree 与 keyset 索引路径。
