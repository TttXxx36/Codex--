## 实施计划与决策

1. 将 app-server 输出统一为 camelCase，同时让 connect 配置输入接受 camelCase 并归一化为既有内部 kebab-case；补充双向/未知值回归。
2. 对非 OpenAI Responses 上游在请求边界把非 `function` tool 规范化为 Responses function 定义，清洗 `tool_choice` 与历史 custom tool call；保留已有 Chat Completions 转换路径。

4. Release 解析资产级 `sha256`/`hash`，把 hash 传到 manager，安装包写入前校验；不引入签名系统或 ZIP 解压配额等需求外重构。
